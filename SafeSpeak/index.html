ABOUT THE PROJECT

AI-assisted communication safety

SafeSpeak is a prototype demonstrating how a pre-trained TensorFlow.js text toxicity model can assist with online communication moderation in an AUF environment.

The system is intended to assist human moderators and should not be used as the sole basis for blocking or penalizing users.
